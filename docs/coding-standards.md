# Coding Standards

## General engineering standards

- Keep modules small and purposeful.
- Prefer explicitness over hidden magic.
- Avoid premature abstraction.
- Document public structures and critical invariants.
- Make failures diagnosable.
- Keep tests close to behavior.

## AI-assisted implementation rules

- No silent architecture drift.
- No speculative feature expansion.
- No mixing future-phase features into current-phase work.
- Always explain tradeoffs when deviating.
